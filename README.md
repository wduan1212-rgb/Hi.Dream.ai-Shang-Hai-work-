# HiDream.ai Shanghai Creative Workspace

智象未来上海海外互动营销内容创作工作台，是一个单文件 HTML 工具站，用于把多个产品的 AI 视频提示词、口播、花字、评论回复和灵感记录集中到一个可直接打开的工作台里。

## 核心文件

| 文件 | 说明 |
| --- | --- |
| `智象未来上海融合创作平台.html` | 最终可使用的网站文件，已内嵌 logo 和主要视觉资源，可直接在浏览器打开。 |
| `build_fusion_html.mjs` | 合并与生成脚本，用于从两个源 HTML 重新生成融合版网站。 |
| `自运营快速创作平台.html` | 自运营产品内容源文件，提供直发梳、磨脚器、脱毛仪、黑头仪的素材与提示词功能。 |
| `冰丝凉凉裤快速创作平台.html` | 冰丝凉凉裤内容源文件，融合后保留 15 个 AI 视频提示词核心模块。 |
| `assets/hidream-logo-white.png` | HiDream.ai logo 源文件，生成时会转为 base64 内嵌到最终 HTML。 |

## 网站功能

- `Prompt Hub`：保留冰丝凉凉裤 15 个 AI 视频提示词模块，去除了产品概述、参考图和最近生成历史，让页面聚焦提示词生成。
- `Hair Brush / Foot File / Trimmer / Pore Vacuum`：四个自运营产品默认进入 AI 视频提示词主工作流。
- `运营素材库`：将四个产品的口播、花字、评论回复收纳到独立素材库中，支持按产品、素材类型和关键词筛选。
- `全局搜索`：可搜索跨产品素材与提示词内容，并支持定位、复制、存入灵感。
- `灵感备忘录`：右下角悬浮球打开随手记录面板，支持颜色标记、调用、一键复制输入和复制全部。
- `最近复制`：保留近期复制内容，便于快速回找和复用。
- `单文件部署`：最终 HTML 已将 logo 以 base64 内嵌，不依赖外部 logo 文件即可运行。

## 使用方式

直接用浏览器打开：

```text
智象未来上海融合创作平台.html
```

如果需要从源文件重新生成最终网站，确保当前目录保留两个源 HTML 和 `assets/hidream-logo-white.png`，然后运行：

```bash
node build_fusion_html.mjs
```

生成脚本会输出新的 `智象未来上海融合创作平台.html`。在 macOS 上脚本会调用 `sips` 压缩内嵌参考图，以减小最终 HTML 体积。

## 产品结构

1. 首页控制台：品牌、产品切换、当前模块状态、搜索入口、素材库入口和灵感入口。
2. AI 提示词工作区：四个自运营产品以 AI 视频提示词为主要工作流，减少口播/花字/评论模块对页面的占用。
3. 运营素材库：保留原始口播、花字、评论回复功能，但改为抽屉式调用。
4. 灵感记录：用于临时保存提示词片段、镜头变量和创意方向。

## 设计方向

界面采用深色科技风、蓝紫高亮和紧凑工作台布局。整体目标不是营销落地页，而是面向内容运营人员的高频创作工具：减少冗余信息，保持功能完整，并让搜索、复制、记录和切换更顺手。
